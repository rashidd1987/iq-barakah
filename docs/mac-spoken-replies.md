# Голосовые поручения для Mac

Владелец отправляет голосовое в личный чат Reports, проверяет расшифровку и нажимает «Выполнить на Mac» → «Запустить на Mac». Бот подтверждает приём голосом. Mac возвращает полный текст и короткую озвучку (до 65 секунд). Длинные отчёты остаются полностью доступны текстом.

Озвучка: системный русский голос Milena, локальный ffmpeg → OGG/Opus. Новые облачные ключи не требуются. Локальный runtime включает scripts/spoken_result.py. Для текстовой проверки голосового результата: `/macvoice Покажи статистику Instagram за последние 7 дней`.

Токены аккаунтов не передаются модели или озвучке. Доступен тот же набор инструментов Mac; выдача разрешений Instagram сама по себе не добавляет инструменты публикации или переписки. При недоступной озвучке владелец получает текст и явное уведомление.

Проверено: 133 теста исходной ветки Reports, 113 тестов на базе production; локальный OGG/Opus имеет ненулевую длительность. Production обновлён до df59e4dad59e751798229eaa07fe48b206f316a4. Для реального голосового поручения c2725cfd0c3f Mac сформировал озвучку и передал результат; голосовое сообщение результата видно в Telegram. Сам запрос Instagram завершился ошибкой доступа/API, поэтому озвучено сообщение об ошибке, а успешное получение актуальной статистики этой проверкой не подтверждено. Соединение Mac с Reports остаётся нестабильным и требует отдельной проверки сети.


## Восстановление сети 23 ноября 2026

Happ Plus подключён к существующему серверу «Швейцария». Instagram Insights идёт через VPN. Для Reports добавлена необязательная настройка `reports_interface: "en0"` в приватном конфиге Mac: curl привязывает только HTTPS-запросы Reports к физическому Wi-Fi, обходя неработающий для Amvera VPN-маршрут. Проверка TLS и авторизация сохранены. На Mac с другим физическим интерфейсом настройку нужно изменить или убрать.

Восемь тестов worker прошли. Пять последовательных авторизованных проверок Reports успешны. Задача Telegram `bd7e3d43e993` завершилась `done`: получены семь дневных значений охвата Instagram; текст и голосовой результат длительностью 47 секунд видны в Telegram. Эта проверка заменяет прежний неуспешный сетевой smoke. Длительная доступность VPN зависит от провайдера; проверен текущий сеанс.


## Прямой приём голоса и мужская озвучка

После распознавания голосовое владельца в личном чате сразу ставится в очередь Mac; два нажатия больше не требуются. Переменная `MAC_VOICE_AUTO_RUN=0` возвращает прежний выбор действия. Ключ задачи основан на ID исходного голосового сообщения: повторная доставка не запускает задачу снова. Production-подтверждения не изменены.

На Mac установлен русский голос `Yuri (Enhanced)`. Выбор голоса и темпа находится в приватном файле `~/.openjarvis/voice-preferences.json`: `voice` (`Milena`, `Yuri`, `Yuri (Enhanced)`) и `rate` (120–230). Подтверждение приёма — отдельный статический OGG в Reports, также озвученный Юрием. Gmail остаётся readonly: отчёт содержит темы и отправителей до десяти непрочитанных писем, без тел и вложений.


## Onyx для постоянных ответов

По выбору владельца включена серверная нейросетевая озвучка Onyx через существующий OpenAI-ключ Reports. Голосовые владельца принимаются сразу, без кнопок. Подтверждение генерируется один раз, результаты — один раз на ID задачи, в приватном каталоге `onyx-voice` постоянного хранилища. Перед платным вызовом создаётся эксклюзивный маркер; после сбоя запрос автоматически не повторяется. При сбое озвучки текстовый результат остаётся доступным.

Gmail озвучивается кратко: количество писем в выборке, число уведомлений безопасности и до четырёх остальных тем. Адреса, ссылки и длинные идентификаторы удаляются из озвучки, текст ограничен 650 символами. Полный отчёт остаётся в Telegram текстом. Mac получает `voice_engine=server-onyx`, чтобы не делать ненужную локальную озвучку. Production Approval Center остаётся отдельным от автоматического приёма голосовых задач.

## Бесплатный голос по умолчанию

По новому выбору владельца стандартные голосовые поручения и `/macvoice задача` используют локального Юрия. Команда `/mac задача` остаётся текстовой. Платный Onyx выбирается отдельно командой `/onyx задача` либо обращением «Оникс, …» / «Onyx, …» в начале голосового. Упоминание Onyx в середине фразы не включает оплату. Выбранный режим хранится в стабильном источнике задачи `voice:onyx:…`; по умолчанию сервер не вызывает синтез OpenAI ни для приёма, ни для результата. Распознавание входящих голосовых по-прежнему использует платный API.


Проверено в production (`5989d13`, approval workflow `45144832783`): `/macvoice` создал задачу `f7a5b8bbad63` с локальным аудио Юрия; `/onyx` создал `6c63ae3ddf84` без локального синтеза, с серверным ответом Onyx. Оба задания Gmail завершились `done`; в Telegram видны голосовой результат Юрия и Onyx. Проверки: 149 тестов исходной ветки, 127 на production-базе. Префиксы голосового обращения проверены тестами; отдельная новая запись владельца с обращением «Оникс» в этой проверке не использовалась.


## Имена по выбору владельца

Джарвас (`Джарвас, …`, `Jarvas, …` или `/jarvas задача`) выбирает платный голос Onyx. Оникс (`Оникс, …`, `Onyx, …` или `/onyx задача`) выбирает бесплатного Юрия. Старое значение команды `/onyx` заменено на бесплатное. Без имени, а также по `/macvoice`, используется Юрий; `/mac` остаётся текстовым. Выбранный платный режим по-прежнему хранится в источнике `voice:onyx:…`, где onyx — техническое имя голоса, а не обращение пользователя. Распознавание входящих голосовых остаётся платным.
