# Аудит проекта IQ Barakah

Дата: 2026-08-03  
Область проверки: активный Telegram-бот `bot_v2`, PWA API, клиентские приложения,
release/safety workflow и конфигурация зависимостей. Production-сервисы и данные не
проверялись и не изменялись.

## Итог

Критических изменений, которые можно безопасно внести без доступа к конфигурации
окружения, не выявлено. Python-исходники компилируются, а 11 доступных тестов
безопасности проходят. До следующего релиза рекомендуется устранить два риска
высокого приоритета ниже.

## Находки

### Высокий приоритет

1. **Предсказуемый секрет внутреннего PWA API.** `bot_v2/config.py` и
   `ACTIVE/pwa_api/main.py` используют одинаковое значение
   `pwa-internal-secret`, если переменная окружения не задана. В таком окружении
   endpoint подтверждения Telegram-сессии можно вызвать без знания уникального
   секрета. Следует задать единый случайный секрет в обоих сервисах, затем убрать
   fallback и завершать запуск с понятной ошибкой при его отсутствии. Перед
   изменением кода нужно проверить, что production использует согласованные
   `PWA_BOT_SECRET` и `BOT_SECRET`.

2. **Изменение схемы БД при запуске.** `bot_v2/db/engine.py:create_tables()`
   выполняет `create_all()` и `_ensure_compat_columns()`, включая `ALTER TABLE` и
   создание таблицы. Это обходит Alembic, усложняет откат и даёт процессу бота
   избыточные DDL-права. Изменения следует перенести в версионированную миграцию,
   после чего оставить приложению только проверку совместимости схемы.

### Средний приоритет

3. **Состояние legacy-бота хранится в Git.** Файл `bot/bot_state.pkl` отслеживается
   репозиторием. Pickle нельзя безопасно загружать из недоверенного источника; кроме
   того, state-файл может содержать пользовательские данные. Нужно проверить его
   содержимое и использование, затем согласованно удалить из истории/репозитория и
   добавить маску в `.gitignore`.

4. **Неполная воспроизводимость проверок.** В корневом окружении отсутствуют
   `pytest` и `aiohttp`, поэтому полный набор тестов нельзя запустить сразу после
   checkout. Стоит выделить dev/test requirements и запускать один документированный
   набор команд в CI.

### Низкий приоритет

5. **Документация структуры устарела.** `CLAUDE.md` описывает миграции 001–003,
   хотя в репозитории уже есть 004–006, и не полностью отражает текущие PWA/mobile
   каталоги. Это повышает вероятность работы не с тем приложением.

## Выполненные проверки

- `python -m compileall -q bot_v2 report_bot ACTIVE/pwa_api` — успешно.
- `python -m unittest discover -s report_bot -p 'test_*.py' -v` — 11 тестов
  успешно; импорт `test_report_bot` остановлен из-за отсутствующего `aiohttp`.
- `python -m pytest -q` — не запущен: модуль `pytest` отсутствует.
- Проверены tracked-файлы состояния, места чтения секретов, manifest зависимостей и
  workflow безопасности; деплой, сеть, production и платежи не затрагивались.
