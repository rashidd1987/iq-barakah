# Защищённые видео уроков

Видео не должны лежать в Git, `ACTIVE/mobile`, PWA-сборке или публичной папке
сайта. Основной production-режим — закрытое S3-совместимое объектное хранилище.
Локальное постоянное хранилище Amvera остаётся резервным режимом.

## Переменные `iq-barakah-pwa-api`

- `VIDEO_STORAGE_BACKEND=s3` — основной production-режим. Значение `local`
  включает прежнюю выдачу из `/data`.
- `VIDEO_S3_ENDPOINT_URL` — HTTPS endpoint провайдера, например endpoint
  Yandex Object Storage или Selectel.
- `VIDEO_S3_REGION` — регион провайдера, для Yandex по умолчанию
  `ru-central1`.
- `VIDEO_S3_BUCKET` — имя закрытого bucket.
- `VIDEO_S3_KEY_PREFIX` — папка объектов, по умолчанию `lesson-videos`.
- `VIDEO_S3_ACCESS_KEY_ID` — идентификатор сервисного ключа, сохранить как
  секрет.
- `VIDEO_S3_SECRET_ACCESS_KEY` — секрет сервисного ключа, сохранить как секрет.
- `VIDEO_URL_TTL_SECONDS` — необязательно; время жизни ссылки, по умолчанию
  7200 секунд, допустимо от 300 до 14400.
- `VIDEO_SIGNING_SECRET` — требуется только для резервного режима `local`;
  отдельная случайная строка не короче 32 символов.
- `VIDEO_STORAGE_DIR` — только для `local`, по умолчанию
  `/data/lesson_videos`.

При неполной или неверной конфигурации API работает как раньше, но видео не
отдаёт. На публичный URL или другой backend автоматически не переключается.

## Подготовка файла

1. Экспортировать MP4 с H.264-видео и AAC-аудио (`faststart`).
2. Удалить GPS, модель телефона, дату съёмки и остальные метаданные.
3. Дать непрозрачный id из строчных латинских букв, цифр, `_` и `-`, например
   `a-01-intro`.
4. Загрузить файл в закрытый bucket как
   `lesson-videos/a-01-intro.mp4`. Не делать объект или bucket публичным и не
   помещать файл в репозиторий.
5. Включить версионирование bucket и настроить независимую резервную копию в
   другом сервисе. Удаление старых версий ограничить отдельной политикой.

Если исходный MOV находится в опубликованном файле Яндекс Диска, его можно
перенести без ручного скачивания. Команда получает временный download URL через
официальный API, скачивает файл во временный каталог, удаляет метаданные,
перекодирует в H.264/AAC MP4 и загружает объект в закрытый bucket:

```bash
cd ACTIVE/pwa_api
PYTHONPATH=. python scripts/import_yandex_disk_video.py \
  --public-url 'https://disk.yandex.ru/i/...' \
  --video-id 'a-01-intro'
```

Команда требует `ffmpeg` и перечисленные выше `VIDEO_S3_*` переменные. Исходник
и MP4 удаляются из временного каталога после завершения. Секретные ключи нельзя
передавать аргументами команды, сохранять в Git или отправлять в чат.

Для PWA bucket должен разрешать CORS только от домена приложения:

```json
[
  {
    "AllowedOrigins": ["https://iq-barakah.ru"],
    "AllowedMethods": ["GET", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["Accept-Ranges", "Content-Length", "Content-Range"],
    "MaxAgeSeconds": 3600
  }
]
```

Для локального аварийного режима тот же файл располагается как
`/data/lesson_videos/a-01-intro.mp4`, а `VIDEO_STORAGE_BACKEND` меняется на
`local`. Это ручное действие: автоматического переключения нет, чтобы ошибка
конфигурации не ослабила защиту незаметно.

## Привязка к уроку

В соответствующем объекте `ACTIVE/pwa_api/content/<уровень>.json` добавить:

```json
"video": {
  "id": "a-01-intro",
  "title": "Введение в первый шаг"
}
```

Прямое поле `video.url` намеренно игнорируется. После авторизованного запроса
урока API заменяет `id` короткоживущей S3-подписанной ссылкой. Объект остаётся
закрытым, ссылка поддерживает HTTP Range для перемотки и перестаёт работать
после срока действия. В режиме `local` ссылка дополнительно содержит подпись
IQ Barakah и ведёт на потоковый endpoint API.

## Граница защиты

Кнопка скачивания и контекстное меню скрыты в PWA, постоянного публичного URL
нет. Это защищает от случайного скачивания и простого копирования ссылки, но
браузер пользователя всё равно получает видеопоток. Полностью запретить запись
экрана невозможно. Для коммерческого DRM в будущем потребуется отдельный
видеопровайдер с Widevine/FairPlay.
